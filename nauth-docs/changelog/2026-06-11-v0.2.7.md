## Changed

- **nauth-toolkit is now open source under the MIT license** --- every `@nauth-toolkit/*` package on npm now ships with the MIT license, free for commercial and non-commercial use. The complete source code, including all example apps, is public at [github.com/noorixorg/nauth-toolkit](https://github.com/noorixorg/nauth-toolkit)

{/* truncate */}

No code changes in this release --- existing integrations are unaffected. Update at your convenience:

```bash
npm install @nauth-toolkit/core@latest @nauth-toolkit/nestjs@latest
```

Found a bug or want to contribute? [Issues](https://github.com/noorixorg/nauth-toolkit/issues) and [discussions](https://github.com/noorixorg/nauth-toolkit/discussions) are open.
