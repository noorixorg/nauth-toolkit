## Added

- **Anonymous usage telemetry (opt-out)** --- nauth-toolkit now reports anonymous usage data so development effort goes where it matters: which token delivery modes, MFA policies, and provider packages are actually used. Only the *shape* of your configuration is sent (enums, booleans, provider names) --- never PII, IP addresses, secrets, domains, or configuration values. See [exactly what is sent](/docs/concepts/telemetry).

{/* truncate */}

Telemetry never runs inside a request path, adds zero startup latency, and fails silently. A one-time notice is logged on first boot.

**Opting out** takes one environment variable:

```bash
NAUTH_TELEMETRY_DISABLED=1
```

or in code:

```typescript
const authConfig = {
  telemetry: { enabled: false },
};
```

`DO_NOT_TRACK=1` is honored, and telemetry is always disabled in CI and tests.
