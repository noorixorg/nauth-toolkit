# Introduction

**nauth-toolkit** is a platform-agnostic authentication library for Node.js. It runs inside your application as an embedded library—not a SaaS service, proxy, or microservice. Authentication logic executes in your process, using your database and infrastructure. Add complete authentication to NestJS, Express, Fastify, or any Node.js framework without vendor lock-in.

The inspiration was to free developers from commercial SaaS services (AWS Cognito, Auth0) that provide limited UI control and complex social auth in hybrid mobile apps. This toolkit enables seamless, integrated authentication without heavy lifting—yet with all features of a commercial platform.

Core dependencies are minimal: Argon2 for hashing, jose for JWT, Zod for validation. Optional features use lightweight packages: SimpleWebAuthn for passkeys, MaxMind GeoIP2 for geolocation.

:::warning Under Active Development
nauth-toolkit is under active development. Version 0.1.0 implements core features including email/password authentication, social login, and MFA. **API may change. Not recommended for production yet.** Contributions welcome on [GitHub](https://github.com/nauth-toolkit/nauth-toolkit).
:::

Ready to start? Check out [Quick Start](/docs/quick-start) to configure nauth-toolkit.

## Framework Support

| Framework | Status | Package |
|-----------|--------|---------|
| **NestJS** | Full adapter | `@nauth-toolkit/nestjs` |
| **Express** | Built-in adapter | `@nauth-toolkit/core` |
| **Fastify** | Built-in adapter | `@nauth-toolkit/core` |
| **Koa/Hapi** | Create custom adapter | `@nauth-toolkit/core` |

All frameworks use the same core services. Adapters handle framework-specific integration (middleware/hooks, request/response wrapping, context management).

## Why nauth-toolkit?

### vs SaaS Authentication Providers

**What you gain:**
- Complete control over code and data
- No vendor lock-in or usage-based pricing
- Customize flows without limitations
- Data in your database, your infrastructure

**What you trade:**
- You manage infrastructure and security audits
- No managed compliance certifications (HIPAA, SOC2)
- Limited to Node.js ecosystem

### When to Choose nauth-toolkit

**Good fit:**
- Need full control over auth logic
- Want predictable infrastructure costs
- Require deep customization
- Building on Node.js (NestJS, Express, Fastify)

**Consider SaaS:**
- Need OAuth/OIDC provider for third-party apps
- Require managed compliance certifications
- Want zero infrastructure responsibility
- Need 40+ pre-integrated social providers

## What's Not Included (Yet)

**Roadmap:**
- OAuth 2.0 provider (can consume, not provide)
- SAML 2.0 for enterprise SSO
- Additional social providers (GitHub, Discord, LinkedIn)
- Advanced RBAC with role hierarchies
- Enterprise directory sync (LDAP, AD)
