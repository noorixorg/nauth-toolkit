# SMSTemplateType

**Package:** `@nauth-toolkit/core`
**Type:** Enum

Template type identifiers used by the SMS template engine and SMS providers.

## Values

| Name | Value | Description |
| ---- | ----- | ----------- |
| `VERIFICATION` | `verification` | Phone verification codes |
| `MFA` | `mfa` | MFA verification codes |
| `PASSWORD_RESET` | `passwordReset` | Password reset codes |
